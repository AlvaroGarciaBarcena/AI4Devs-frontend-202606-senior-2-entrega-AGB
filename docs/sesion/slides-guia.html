Slide 8 - Reemplazar Cypress Nueva: Config 1
PARTE 1: Configuración 1: Playwright + MCP Agéntico
Interacción semántica en vivo y generación de tests con Antigravity
  • Protocolo MCP (@playwright/mcp): Conexión nativa stdio que entrega herramientas de navegador al LLM.
  • Interacción por Roles AOM: El agente opera con getByRole('searchbox'), getByRole('button') y regiones aria-live.
  • Generación en Vivo: Antigravity explora la aplicación abierta, prueba interacciones y sintetiza el test en TypeScript nativo.
  • Producción y CI: Tests 100% deterministas que se ejecutan en CI sin requerir APIs de IA en runtime.
Notas del orador: "Mostraremos cómo configurar mcp_config.json y cómo Antigravity interactúa con el buscador de candidatos de nuestro Kanban para crear candidate-search.spec.ts."
Slide 9 - Actualizar Playwright Nueva: Parte 2 init-agents
PARTE 2: Industrialización con npx playwright init-agents
La tríada oficial de agentes autónomos de Playwright

Comando oficial: npx playwright init-agents --loop=vscode|claude|codex

  • 🗺️ Planner Agent: Explora la UI viva y redacta un plan de pruebas en Markdown (test-plan.md).
  • ⚙️ Generator Agent: Transforma el plan Markdown en código .spec.ts validando locators en vivo.
  • 🩹 Healer Agent (Self-Healing): Diagnostica tests fallidos y auto-repara selectores ante cambios de diseño.
  • 🌱 seed.spec.ts: El arnés determinista que proporciona autenticación y estado limpio para los agentes.
Notas del orador: "Playwright ha dado un paso de gigante al empaquetar estos agentes en su CLI. Ya no dependemos de un prompt suelto: tenemos agentes especializados para planificar, generar y auto-reparar tests cuando la UI cambia."
Slide 10 - Actualizar Midscene Ajustar a Config 2
Configuración 2: Testing Multimodal con Visión (Midscene)
Set-of-Mark Prompting y modelos de visión (GPT-4o)
  • Zero Selectors: La IA inspecciona la pantalla mediante capturas de imagen.
  • Lenguaje Natural: .ai('buscar candidato "José"') y .aiAssert('queda 1 candidato').
  • AOM/MCP vs Visión (Trade-offs Senior):
    • Playwright MCP / Agents: Ejecución en milisegundos, coste $0 en CI, determinista. Ideal para UIs accesibles.
    • Midscene (Visión): Mayor latencia y coste en tokens. Ideal para Canvas, WebGL o interfaces sin accesibilidad.
Notas del orador: "Como arquitectos debemos saber cuándo usar cada enfoque: AOM para SPAs estructuradas y robustas en CI; Visión multimodal para UIs donde no tenemos control del markup."
Slide 11 - Nueva Diapositiva Nueva
Verificar con Criterio: Calidad más allá del "Verde"
Cómo auditar críticamente los tests generados por IA
  • El peligro del falso verde: Tests que pasan porque no asertan nada o enmascaran errores con esperas infinitas.
  • Test Mutation en Directo: Modificamos intencionalmente una línea del código fuente (ej. comentamos la devolución de foco en CandidateSearch.tsx) y verificamos que el test falle en rojo.
  • Trace Viewer: El post-mortem definitivo para auditar acciones, red y asincronías.
Notas del orador: "Si la IA genera un test y pasa en verde, nuestro trabajo como ingenieros no ha terminado: mutamos el código fuente para demostrar que el test detecta la rotura real."
